A tenant can run many fleets at once. Each is isolated: its own agents, evals, sessions, and incidents. One fleet never touches another's data.
+ Add Fleet
Add Fleet creates a new isolated fleet and runs its setup (workflow → grading → connect). This is where the setup wizard lives now. It never re-onboards the tenant. Each fleet's Guardrails and outcome Contract are managed per fleet.
